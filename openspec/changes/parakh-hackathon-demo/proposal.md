## Why

Indian traders often need to interpret scattered public-record signals before extending trade credit, yet the current journey is difficult to understand and unsafe to oversimplify. A fixture-only, independently built demo can show a clearer citizen journey for the Build What Moves India hackathon without accessing live records, handling sensitive information, or risking production Parakh.

## What Changes

- Add a standalone static demo with a curated scenario selector, deterministic simulated check, and inspectable report.
- Add fictional fixture data that demonstrates five common counterparty-research situations without deriving from real people, businesses, addresses, or cases.
- Add report safety language, plain-language limitations, browser print/export, mobile accessibility, and a no-external-calls guard.
- Add submission, methodology, compliance, production-boundary, judge, and Codex-contribution documentation.
- Add Superspec-compatible artifacts so research, requirements, TDD execution, verification, and closeout are traceable.

## Capabilities

### New Capabilities
- `synthetic-fixture-data`: Typed, validated fictional profiles and simulated public-record observations.
- `demo-report-journey`: A complete no-sign-in scenario-to-report browser journey.
- `safety-report-export`: Safety disclosure, observation semantics, external-call boundary, and browser-print report export.
- `hackathon-documentation`: Judge-facing and traceability documentation for the independent prototype.

### Modified Capabilities

None. This repository has no existing capabilities.

## Impact

New Vite/React client files, test suite, static assets only when independently created, print CSS, docs, OpenSpec artifacts, a new GitHub repository, and a separate Vercel project. No production repository, API, database, account, payment, messaging, government system, or credential is affected.
